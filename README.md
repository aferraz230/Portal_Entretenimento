## Meu Portal de Entretenimento Digital

### Objetivo
Criar uma página temática com três seções — Filmes e Séries, Música e Podcasts, Games e Tecnologia — aplicando os recursos de HTML e CSS trabalhados na Agenda 13.

### Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta `Portal_Entretenimento`.
3. Mantenha `portal.html`, `reset.css`, `estilo.css` e a pasta `imagens` na mesma estrutura em que foram entregues.
4. Abra `portal.html` em um navegador (por exemplo, Google Chrome).

Não é necessário instalar programas ou executar comandos: a página funciona localmente no navegador.

### Arquivos e pastas
- `portal.html`: estrutura da página, com as três seções, títulos, textos e imagens. Também contém exemplos de CSS inline e interno.
- `reset.css`: folha de Reset CSS baseada no modelo de Eric Meyer, carregada antes da folha principal.
- `estilo.css`: folha de estilos externa, com formatação geral, classes, identificadores (IDs), comentários e Flexbox.
- `imagens/`: nove imagens locais usadas nas três seções. Cada seção possui uma imagem de abertura e duas imagens relacionadas ao tema.
- `capturas/`: capturas de tela do código e da página aberta no navegador.
- `interacoes_com_IA.pdf`: registro textual das três etapas de interação com a inteligência artificial.
- `README.md`: este arquivo, com a descrição do projeto e instruções de execução.

### Recursos de CSS utilizados
- **CSS inline:** atributo `style` aplicado ao parágrafo sobre cinema na seção Filmes e Séries (`font-style: italic`).
- **CSS interno:** bloco `<style>` dentro do `<head>`, com as regras da classe `.destaque` e do ID `#apresentacao`.
- **CSS externo:** arquivo `estilo.css`, vinculado ao HTML por meio da tag `<link>`.
- **CSS Reset:** arquivo `reset.css`, vinculado antes de `estilo.css` para retirar formatações padrão do navegador.
- **Classes:** `.secao`, `.titulo-secao`, `.imagem-secao`, `.filmes`, `.musica` e `.games`.
- **IDs:** `#titulo-principal` e `#apresentacao`.
- **Flexbox:** a classe `.container` utiliza `display: flex` e `flex-direction: row` para organizar as três seções lado a lado. `flex-grow` e `flex-basis` ajudam a distribuir o espaço entre elas.
- **Comentários CSS e HTML:** comentários foram incluídos para identificar e explicar partes do código.
